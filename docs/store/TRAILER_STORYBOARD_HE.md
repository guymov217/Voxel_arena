# WRECKSMITH — מהלך הטריילר החדש

75 שניות. טון: קרבות רציניים עם הומור שנובע מהפיזיקה ומהביטחון המופרז של הגלדיאטור.

| זמן | תמונה ובימוי | סאונד |
|---|---|---|
| 0–6 | קלוז־אפ מכה, מעבר לשוט רחב של התגובה, חשיפת הזירה מלמעלה | פגיעה מיידית, קהל, פתיחה מוזיקלית חזקה |
| 6–16 | כניסה לנפחייה; בניית ידית, ראש ולהב; סיבוב סביב הנשק; אותו גרזן ביד ופגיעה | קצב בנייה, עלייה קצרה, חזרה לקרב |
| 16–28 | קומבו בזמן אמת: מכה, מכה חוזרת ובעיטה. אחריו פטיש, קטיעה ותפיסה־הטלה | המגעים האמיתיים בחזית, המוזיקה מפנה להם מקום |
| 28–33 | שוט רחב מוחזק: הגרזן תקוע, השתהות ומשיכה החוצה. MINOR COMPLICATION. | המוזיקה נחלשת כמעט לגמרי; נשימות, משיכה וקהל |
| 33–40 | האויב פוגע בשריון; מעבר לרופא, התאמת וו והצגתו | מעבר רגוע יותר, צלילי טיפול ומתכת |
| 40–44 | מעבר בחצר ואימון לפני החזרה לזירה | הקצב חוזר ונבנה |
| 44–57 | חשיפת קיקלופ מלמטה, מכה רחבה, חיתוך לברך; אריה ומינוטאור | עלייה מוזיקלית, כובד במכות הגדולות |
| 57–67 | קרב קבוצתי, הפלת יריב, מכת סיום עם האטה קצרה, רגע ניצחון | שיא, מרווח לפני המכה ואז הדהוד |
| 67–70 | שבירת רגע הניצחון עם הסתערות האריה | נפילת מוזיקה ותגובה פיזית קומית |
| 70–75 | לוגו WRECKSMITH וכיתוב MAKE IT. BREAK IT. | סיום מוזיקלי והדהוד שדועך |

הוראות הפקה, רשימת שוטים מלאה, מקורות השראה ומצב הבדיקות: `tools/TRAILER.md`.
הפעלה ב־Windows: `tools\make_trailer75.bat`.
הקומיט מכיל מערכת צילום ועריכה; הוא אינו מכיל מאסטר גיימפליי סופי שאושר לפרסום.
